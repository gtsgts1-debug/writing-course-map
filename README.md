# 高雄市國中小寫作課程地圖

提供國中小教師備課查詢的寫作課程地圖網站。依年級、文體與課本版本，快速找到各學期的寫作教學重點、題目範例與搭配課文。

🔗 **網站連結：<https://gtsgts1-debug.github.io/writing-course-map/>**

## 資料來源

《高雄市國中小寫作課程地圖－寫作能力發展與教學指引》
高雄市政府教育局，115 年 10 月初版
指導教授：楊裕貿（國立臺中教育大學）

## 網站內容

| 分頁 | 說明 |
|---|---|
| 介紹影片 | 約 5 分鐘的課程地圖介紹影片 |
| 課程地圖 | 各學習階段寫作學習重點樹狀圖，可點擊放大 |
| 各學習階段寫作學習表現 | 課綱寫作學習表現條目對照表 |
| 課程規劃 | 46 筆課程項目的檢索介面（預設首頁） |
| 參考資料 | 文體定義、設計理念、各學段規劃總覽、評量檢核指標等 14 章 |
| 寫作電子書 | 翻頁電子書連結 |

## 使用方式

**課程規劃** 分頁可組合以下條件查詢：

- **年級學期**：單選，例如「三上」「七上」
- **文體主題**：可複選，例如記敘＋抒情文、說明文、議論文
- **課本版本**：可複選，南一／康軒／翰林
- **關鍵字搜尋**：比對題目範例、寫作知識與能力、搭配課文，命中處會標色

點選任一張卡片，右側會展開完整內容。

**鍵盤快捷鍵**

| 按鍵 | 功能 |
|---|---|
| `1`～`6` | 依序切換六個分頁 |
| `/` | 跳到搜尋框 |
| `?` | 開啟使用說明 |
| `Esc` | 關閉面板 |

網站支援手機瀏覽與深色模式。

## 更新網站

1. 修改 `index.html`（或替換影片檔）。
2. 推送到 GitHub：

   ```bash
   git add .
   git commit -m "說明這次修改的內容"
   git push
   ```

3. 約 1～2 分鐘後 GitHub Pages 會自動更新，瀏覽器按 `Ctrl+F5`（Mac 為 `Cmd+Shift+R`）強制重新整理即可看到新版。

**注意事項**

- 介紹影片由 `index.html` 內的 `INTRO_VIDEO` 變數指定檔名，更換影片時兩者須一致（大小寫也要相同）。
- 透過 GitHub 網頁上傳的單檔上限為 25 MB；以 git 指令推送則為 100 MB。
- 首次開啟網站會自動顯示「使用說明」，按 ✕ 或 `Esc` 即可關閉。
